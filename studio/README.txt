LABEL STUDIO — how to use it

Open: https://dcollierphoto.github.io/wild-groves-box/studio/
(It isn't linked from the public pages. Bookmark it.)

First time on a device: follow the 5 steps on the page to make a GitHub key and paste it in.
The key stays on that device. "Forget key" removes it.

Add a label: pick the bottle, drop the flat label (PNG, JPG or PDF, 7 x 6.5 in), name it,
optionally add the gold foil layer, check the preview, "Add to the list", then Publish.

Rename / reorder / remove: edit the list, then Publish. Removing only hides a label.

New product: "+ New product", give it a name, a short line and a colour, add at least one label,
then Publish. It gets its own page and a card on the All Products page.

Changes show on the live site about a minute or two after Publish.
