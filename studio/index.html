Label Studio

Add a new label to a bottle, rename or reorder labels, or start a new product. Nothing goes live until you press Publish. This page is private: it only works on a device that has your studio key.

Studio key

The studio needs a key from GitHub once, so it's allowed to save to your site. It stays on this device only.

  1. Open GitHub's new key page and sign in.
  2. Name it Label Studio. Set the expiration as long as GitHub allows.
  3. Under Repository access, choose Only select repositories, then pick wild-groves-box.
  4. Under Permissions, find Contents and set it to Read and write.
  5. Press Generate token, copy it, and paste it below.
